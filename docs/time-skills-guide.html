Log your TaskRay time from what you actually did

Two skills that share one profile. You say "log my time" in Claude Code or Codex, and it reads your calendar and work evidence, proposes calendar events and time records, and writes nothing until you approve.

Get started, or update

Open the Code tab in the Claude desktop app (the </> icon at the top, next to Chat), or open Codex. Paste this line and press Enter. It installs what's missing, signs you in to Kicksaw, and walks you through setup. Allow the prompts it shows you.

Download https://raw.githubusercontent.com/bbold-bb/kicksaw-time-skills/main/SETUP.md with your shell, read all of it, and follow it to set up the Kicksaw time skills.

Already set up? Paste the same line to update to the latest version. Your profile is kept. Then say "log my time".

Writes, after approval

log-time

Finds the days you haven't logged, fills the gaps from evidence, and creates TaskRay time records in Kicksaw-Prod.

Read-only

time-report

Shows what is already logged by project and activity type, your pace against the week or month, and an HTML dashboard.

Setup

Before you install

  1. Paste the setup line

    Paste this into the Code tab in Claude desktop, or into Codex. It checks what's set up, asks once before installing anything, installs the skills, the Salesforce CLI and Python, opens your browser to sign in to the Kicksaw org, and shows you where to connect Calendar and Slack. You'll see prompts asking you to allow each step; Allow is right for these.

    Download https://raw.githubusercontent.com/bbold-bb/kicksaw-time-skills/main/SETUP.md with your shell, read all of it, and follow it to set up the Kicksaw time skills.
    Paste the same line again any time to update or repair your setup. When it finishes, log-time's setup starts on its own, so you can skip to the next step.

  2. Or install by hand

    For technical users. Sign in to the org first with sf org login web -a Kicksaw-Prod. The skills install together because time-report reads the profile log-time creates.

    $ npx skills add bbold-bb/kicksaw-time-skills --agent claude-code --global --skill '*'
    Keep --agent claude-code exactly as written. claude installs nothing, and leaving it off installs into dozens of agent folders in your home directory.

    No npm? Clone the repo and run the installer instead. It also works offline.

    $ git clone https://github.com/bbold-bb/kicksaw-time-skills.git
$ cd kicksaw-time-skills
$ ./install.sh

    If you already have /log-time or /time-report commands in ~/.claude/commands, remove them first or the names collide.

    Using Codex? Install into Codex's skills folder instead. Either command works:

    $ npx skills add bbold-bb/kicksaw-time-skills --agent codex --global --skill '*'
    $ ./install.sh --codex
    Codex uses the same profile as Claude Code, so setting up in one covers both. Questions come as numbered lists instead of pop-ups, and Calendar and Slack need to be connected in Codex itself.

  3. Run it once to build your profile

    In Claude Code, type /log-time. In Codex, type $log-time. Or just say "log my time" in either. The first run is setup only, and it's mostly clicks: it reads what it can from the org and your connectors, and you confirm. No time record is written.

    • Org. Uses Kicksaw-Prod if you're logged in, or offers your logged-in aliases
    • Flux resource. Read from Salesforce
    • Projects. From your Resource Hero assignments and last 90 days of logging. Tick the ones to log against
    • Internal project. Added for everyone, not asked
    • Labels. Default to the client name. Asked only when two would clash
    • Repo folders. Tick the folders that hold your repos. They're matched to projects by name
    • Slack channels. Tick the channels that match each project
    • Colors and Tasks. Whether you color-code projects on your calendar (new events then match), and whether you track work as Google Tasks, so the run asks about them
    • How you work. What fills your week, what leaves no trace, and how much goes through Claude, so unclear time and gaps fit your job
    • Your meetings. Where they're recorded, and which of those tools hold only work meetings. Personal recordings stay out
    • Work hours, timezone, then save. 9 to 5 and your computer's timezone by default, then a summary to save or change

    Folders and channels it can't place are asked about later, on the first run that finds work in them.

    The profile is saved at ~/.claude/kicksaw-time/profile.json, outside the skill folders, so updates never touch it.

  4. How a run goes

    1. Fill your calendar gaps first. Add anything it can't see, like a phone call or a task, so the run finds it
    2. Say "log my time". Leave the date off; it starts from your last record
    3. Approve the calendar events. Answer the questions it lists, then let it write your calendar
    4. Check your calendar. Move or fix anything that looks off, and tell it what changed
    5. Approve the time records. They're written exactly as shown. The skill only changes a record on the day it was written
    6. Talk through unaccounted time. Tell it what you were doing in each gap, and it adds the time
    7. Check the dashboards. Yours opens in your browser. My Hours - Dashboard 2.0 in Salesforce shows the same records

  5. Use it day to day

    Log my timeCovers from your last logged day through today. Or name a range: "fill in yesterday".
    Am I on pace this week?time-report prints hours by project and activity type against your weekly baseline.
    Show me my month as a dashboardOpens the HTML dashboard: totals, allocation used per client, week by week.
